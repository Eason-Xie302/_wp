這學期的網頁程式設計課程，讓我從原本只會寫簡單的 HTML 標籤，到現在能夠獨立運用 JavaScript 進行複雜的 DOM 操作與狀態管理，甚至跨足 Node.js 後端伺服器的建立與 Render 雲端部署。
