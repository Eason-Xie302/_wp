## 期中專案 — 舒爾特方格 (Schulte Grid)

**檔案路徑：** `Midterm/`  
**線上實機展示：** [點我遊玩 (Render 雲端部署)](https://eason-schulte-grid.onrender.com)  
*(備註：使用 Render 免費方案，首次載入若遇休眠請耐心等待約 30 秒喚醒)*

**專案簡介：** 本專案為經典專注力訓練遊戲「舒爾特方格」的現代化網頁重製版。支援 3x3 至 7x7 動態難度切換，並獨創兩項硬核遊戲機制：
* **🌪️ 隨機互換模式 (Chaos Mode)：** 系統每隔 1.5 秒動態抽取多組方格進行位置互換，極大化考驗動態追蹤能力。
* **👁️ 極限盲解模式 (Blind Mode)：** 遊戲啟動後隱藏所有數字，考驗瞬間記憶。點錯將觸發 1 秒時間懲罰與 0.5 秒的全局閃現補救。

**技術重點：** * **前端：** Vanilla JavaScript (ES6+), CSS3 Flexbox/Grid 雙欄響應式佈局。
* **狀態管理：** 精準控制非同步計時器 (`setTimeout`, `setInterval`) 避免記憶體流失與狀態衝突。
* **資料持久化：** 使用 HTML5 `localStorage` 實作各難度的本地排行榜。
* **部署：** Node.js + Express 本地伺服器，並部署至 Render 雲端平台。
